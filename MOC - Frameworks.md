# Mapa de Conteúdo — Frameworks de Raciocínio

> 10 frameworks registrados no [[ler-runtime/CONHECIMENTO.md]]

## Ciclo PDCA (Plan-Do-Check-Act)
Loop clássico de melhoria contínua adaptado para engenharia.
- **Uso:** Qualquer processo iterativo
- **Fonte:** meta_cognition

## 5 Porquês (5 Whys)
Análise de causa raiz: pergunte "por quê?" 5 vezes.
- **Uso:** Debugging, incidentes, bugs recorrentes
- **Fonte:** meta_cognition

## MECE (Mutually Exclusive, Collectively Exhaustive)
Partições sem sobreposição que cobrem todo o espaço.
- **Uso:** Classificação, taxonomia, design de sistemas
- **Fonte:** meta_cognition

## FIRST Principles (Testes)
Fast, Isolated, Repeatable, Self-validating, Timely.
- **Uso:** Todo teste que se preze
- **Fonte:** meta_cognition

## Árvore de Decisão para Fallback
Múltiplas fontes em ordem de preferência com fallback automático.
- **Uso:** Metadata search (AcoustID → iTunes → MusicBrainz)
- **Fonte:** meta_cognition

## Snapshot Imutável
Cada salvamento é um snapshot timestampado, nunca overwrite.
- **Uso:** Persistência Android, preservação de histórico
- **Fonte:** meta_cognition

## Aprendizado Contínuo (Auto-Learning)
Acumula conhecimento automaticamente entre sessões.
- **Uso:** EcoSystemUmGrau (vigilante + knowledge graph + CONHECIMENTO.md)
- **Fonte:** meta_cognition

## Cascata de Interação (CI)
N1 = seletor direto → N2 = semântico → N3 = coordenadas → N4 = OCR/template
- **Uso:** Automação web/mobile/desktop
- **Fonte:** session

## OODA-Nav
Observe → Orient → Decide → Act adaptado para navegação automatizada.
- **Uso:** Navegação em interfaces desconhecidas (ciclo <3s)
- **Fonte:** session

## 3-Scan Pre-Action
3 scans antes de cada ação: elementos visíveis, modais, estado de loading.
- **Uso:** Qualquer interação automatizada
- **Fonte:** session
