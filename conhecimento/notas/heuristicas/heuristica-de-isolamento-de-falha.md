# Heuristica de isolamento de falha

**Dominio:** debugging | **Fonte:** meta_cognition

Quando um sistema falha, isole variaveis UMA de cada vez. Mude exatamente uma coisa entre cada teste. Se voce mudar duas coisas e o bug desaparecer, voce nao sabe qual das duas resolveu.
