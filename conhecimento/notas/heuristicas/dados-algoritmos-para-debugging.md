# Dados > Algoritmos para debugging

**Dominio:** debugging | **Fonte:** meta_cognition

Quando um algoritmo parece errado, nao olhe primeiro para o algoritmo. Imprima/inspecione os DADOS que ele esta processando. 90% das vezes o algoritmo esta certo e os dados estao errados (formato inesperado, null onde nao deveria, encoding errado, valores fora de range).
