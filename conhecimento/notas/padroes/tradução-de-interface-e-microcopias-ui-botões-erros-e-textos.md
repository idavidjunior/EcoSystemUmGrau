# Tradução de interface e microcopias (UI): botões, erros e textos curtos

**Fonte:** traducao-texto

Microcopy é todo texto curto de interface: botões, tooltips, mensagens de erro, confirmações e validações. O desafio é traduzir com poucos caracteres, pois o layout foi desenhado para o original e o pt-BR costuma ser 20-30% mais longo que o inglês.

Use verbos de ação claros nos botões ("Excluir", "Salvar", "Enviar"). Erros devem explicar o problema E a solução: em vez de "Erro 403", "Você não tem permissão para ver esta página — solicite acesso ao administrador".

Armadilhas: ignorar convenções de plataforma ("Sign in" é "Entrar", não "Assinar"), usar tom inconsistente entre telas e plurais/gênero fixos em textos com variáveis. Teste sempre no tamanho real do botão: evite quebras que quebram o layout.
